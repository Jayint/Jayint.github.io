## Graph2Env

[GitHub repository](https://github.com/Jayint/Graph2Env)

Graph2Env explores how dependency and repository structure can guide environment construction, with the aim of turning a codebase into a runnable and verifiable setup.

## Repo2Run

[GitHub repository](https://github.com/Jayint/Repo2Run)

Repo2Run is an LLM-agent approach to environment configuration for Python repositories. It focuses on the practical path from repository evidence to an error-free Docker environment.

## Jayint-repo

[GitHub repository](https://github.com/Jayint/Jayint-repo)

Jayint-repo contains experiments and tools for reliable setup, execution, and evaluation of repository environments.
